Edit working-plan.md with the native edit or write tool, then use workflow_update_plan to commit every implementation-plan change during workflow planning.
Provide a one-sentence-or-less English description that accurately describes the entirety of the working plan as it now stands. The description is the plan's display title: never describe only the latest edit or diff.
Draft saves are allowed even when dependencies are incomplete or invalid. If the result includes a dependency warning, fix the reported issue in working-plan.md and save again. Planning cannot finish until every planned change has a standalone **Depends on** field before **What**, containing None or comma-separated canonical PC IDs, and the dependencies form a valid DAG.
