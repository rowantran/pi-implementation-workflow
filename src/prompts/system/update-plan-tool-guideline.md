Use workflow_update_plan with action="prepare" before editing a plan. Edit only the returned draft directory's JSON and Markdown files with native edit or write calls. The tool preserves existing unsaved edits.
Use workflow_update_plan with action="finalize", expectedBaseVersion from prepare, and a concise English description of the entire plan (at most 18 words and 160 characters) to publish a new immutable version. Never describe only the latest edit or diff.
Finalization validates required files, strict JSON metadata, stable slug IDs, readingOrder, and dependency edges. Fix reported errors in the draft and retry; invalid drafts never replace the saved plan. Reconcile stale drafts with the latest version instead of overwriting another session's work. Finalization is a plan snapshot, not a Git commit.
